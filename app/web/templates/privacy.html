Privacy

Where your data goes

{{ instance_brand }} is self-hosted: this instance runs on infrastructure operated by {{ config.INSTANCE_NAME or 'the organization that deployed it' }}. Your rows do not leave that infrastructure to reach a software vendor.

✓
You only ever see what you're granted. Every request is checked against your groups — and an agent you build can never exceed your own access.
✓
Query results stay local. With the CLI, data packages sync to your machine and analysis runs there.
→
Session transcripts are collected. Prompts, tool calls and tool responses flow back to the catalog so your team can spot failure patterns and close knowledge gaps. Raw data rows you query locally do not travel.
✓
You can go off the record. Run /agnes-private in Claude Code to disable telemetry for that session — nothing from it reaches the catalog.
