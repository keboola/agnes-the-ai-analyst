{# Appearance — Light / Dark / System, as one compact row inside the user menu: "Theme" on the left, an icon-only segmented pill on the right. Icon-only so the control fits on a single menu row instead of the two-row label+buttons stack it used to be; the accessible name comes from `aria-label` (the SVGs are `aria-hidden` decoration) and `title` gives the hover tooltip. Drives window.__agnesTheme (defined pre-paint in _theme_resolve.html); wired in app.js, which keys off `id="themeToggle"` + `data-theme-choice`. Included by BOTH chromes (_app_header.html and _app_rail.html) — keep it here rather than duplicating the markup, so the two never drift. The choice is per-browser (localStorage) and overrides the instance default + OS setting. #}
