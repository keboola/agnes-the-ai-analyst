{# The shared page footer — one partial for every chrome that has a footer. Two-part attribution, both config-driven so the public distribution ships no vendor branding: left the PRODUCT — `instance.brand` (default "Agnes") plus the running build, filled from /api/version. A self-hosted operator needs to know what they are running, and this is now the only place that says it on an authed page: the fixed bottom-right build chip (`_version_badge.html`) is retired from the app chromes. Pre-auth `base_login.html` keeps the chip — it has no footer to move it to. right the DEPLOYMENT — `instance.copyright`, rendered ONLY when set. What this replaced, and why: `© {year} {instance.name}` repeated the header brand, and asserted a copyright the deploying org does not hold over software it did not write. Worse, `INSTANCE_COPYRIGHT` was hardcoded empty in the context builder, so the `or 'AI Harness'` fallback fired on every page of every instance — the string operators saw was a leak, not a choice. Both values come off `config` rather than the `instance_brand` / `instance_copyright` context keys, because this partial renders on chromes whose context builders don't set those (see `_config_proxy`, which every builder exposes). `default(…, true)` covers the pages that skip `config` altogether — a missing key resolves to an empty dict, which is falsy, so the brand falls back and the attribution line is simply omitted. Callers pass their chrome's own footer class: {% raw %}{% with footer_class = 'footer' %}{% include '_footer.html' %}{% endwith %}{% endraw %} #} {# One

of inline spans, deliberately NOT a flex row. This partial renders into six different layout contexts — a centered `.container`, the index shell's white band, and `.cloud-chat-empty-foot`, which is a shrink-to-fit item in a flex column. Inline flow asks nothing of any of them: it inherits whatever `text-align` the chrome already sets (all six centre their footer), needs no width of its own, and wraps by itself on narrow viewports. A flex row would have to be told how to align and how wide to be in each one. #}
