Don't have Claude Code yet? Set it up first

A 3-step walkthrough for total beginners — install Claude Code, make a folder, open a terminal. Then use the button above.

{{ ico.icon('chevron', 20) }}
{# OS toggle — one choice applies across every step (CSS-driven) #}
{# Step tabs #}
{# Step 1 — install Claude Code #}

Claude Code is the CLI tool that runs Claude on your machine. {{ instance_brand_short }} plugs into it. ~3 min.

terminal
curl -fsSL https://claude.ai/install.sh | bash
PowerShell
irm https://claude.ai/install.ps1 | iex
{{ ico.icon('bulb', 16) }}No terminal open yet? On macOS press ⌘ Space, type Terminal, hit Enter. On Windows press ⊞, type PowerShell, hit Enter.

Once it finishes, verify with claude --version, then sign in with claude (one-time OAuth in your browser). No Claude license yet? Here's how to get one (Pro / Max 5× / Max 20× / Enterprise).

{# Step 2 — pick a folder #}

This is where {{ instance_brand_short }} — and all your AI projects — will live. ~1 min.

{{ ico.icon('bulb', 16) }}Tip: put it on your Desktop. Easy to find in Finder/Explorer (~/Desktop/{{ workspace_dir }} on macOS, %USERPROFILE%\Desktop\{{ workspace_dir }} on Windows). Your home folder works too — the install runs anywhere.
terminal
mkdir -p ~/Desktop/{{ workspace_dir }} && cd ~/Desktop/{{ workspace_dir }}
PowerShell
New-Item -ItemType Directory -Force -Path "$HOME\Desktop\{{ workspace_dir }}" | Out-Null; Set-Location "$HOME\Desktop\{{ workspace_dir }}"
{{ ico.icon('bulb', 16) }}What does mkdir -p do? It creates a folder (the -p means "don't complain if it already exists"). You'll now have an empty {{ workspace_dir }} folder on your Desktop.
{# Step 3 — open a terminal in the folder #}

You need to "be in" the {{ workspace_dir }} folder before you launch Claude. The cd in step 2 already put you there — this is how to get back if you closed the terminal. ~1 min.

terminal
cd ~/Desktop/{{ workspace_dir }}
PowerShell
Set-Location "$HOME\Desktop\{{ workspace_dir }}"
{{ ico.icon('bulb', 16) }}Prefer drag-and-drop? Type cd and a space, then drag the {{ workspace_dir }} folder onto the terminal window — it pastes the path. Hit Enter.
{{ ico.icon('check-circle', 16) }}You're set up. Now use Set up a new Claude Code at the top of this tab — paste the copied script into Claude and hit Enter.

Having trouble?

Common issues and quick fixes.

{{ ico.icon('chevron', 20) }}
{{ ico.icon('refresh', 17) }} First question errors right after sign-in? Wait a few seconds and ask again. {{ ico.icon('chevron', 16) }}

The connection needs a moment to settle after sign-in. Wait a few seconds, then re-send your question.

{{ ico.icon('tools', 17) }} "MCP endpoint not found"? Re-add the connector over SSE. {{ ico.icon('chevron', 16) }}

An older {{ instance_brand }} release doesn't serve this connector. Remove it (claude mcp remove agnes) and re-add over SSE: claude mcp add --transport sse agnes {{ server_url }}/api/mcp/sse, then restart and authenticate the same way.

{{ ico.icon('warning', 17) }} Can't add a custom connector on Claude.ai? Ask a workspace admin to add it. {{ ico.icon('chevron', 16) }}

Team and Enterprise plans gate custom connectors to workspace admins. Ask an admin to add it once for everyone — use the "Copy request for your admin" button on the Claude.ai tab.

{{ ico.icon('link', 17) }} VS Code sign-in stuck? Clear saved authorizations, then retry. {{ ico.icon('chevron', 16) }}

Run MCP: Clear Saved Authorizations from the Command Palette, remove and re-add the server, then restart VS Code. A stale cached registration is the usual cause.
