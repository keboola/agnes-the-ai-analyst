{# ── Trust marker — the ONE place the three trust claims are spelled ───────── v113. Usage: {% import "macros/_trustmark.html" as trust %} trust.mark(level, own=is_mine) -> icon, for a table cell or a card head trust.mark(level, own=is_mine, form='label') -> icon + word, for a detail-page hero (Written without braces on purpose: a nested comment would close this one — Jinja comments do not nest.) `level` is 'org' | 'verified' | 'community' | anything-else (renders nothing, which is what an instance that has opted out of the community marker wants). Use `level_for()` below to derive it from a row rather than re-implementing the precedence at each callsite — that duplication is exactly how the four old vocabularies came to disagree. `own` only affects the community sentence: "shared by other users" is simply untrue of the thing the reader uploaded ten minutes ago, and a marker that misdescribes what it sits on is worse than none. Same glyph, same meaning ("nobody has verified this"), one honest sentence each. The sentence is carried by BOTH `data-tip` (the page's fast tooltip — the native `title` delay is OS-controlled at 600ms+, far too slow for the only affordance that explains a glyph nobody can read on sight) and `aria-label` (the accessible name, which is what a screen reader actually reads). Never `title`: two bubbles for one glyph, the slow one landing on top of the fast one, is worse than either. `data-tip-instant` drops the shared 120ms anti-flicker delay. That delay is for WIDE targets a crossing pointer sweeps; these are too small to hit by accident. Styling + the full rationale for the ladder: css/trustmark.css. #} {% import "macros/_icon.html" as _trust_ico %} {%- macro level_for(publisher_kind, verification_state='none', show_unverified=True) -%} {#- Precedence, once, for every surface. Organization outranks verified (and the store pins verification_state='none' on org-published rows anyway, so a verified+org row cannot exist); unverified is last and opt-outable. -#} {%- if publisher_kind == 'organization' -%}org {%- elif verification_state == 'verified' -%}verified {%- elif show_unverified -%}community {%- endif -%} {%- endmacro -%} {%- macro _tip(level, own) -%} {%- if level == 'org' -%}Published by your organization. {%- elif level == 'verified' -%}Verified by your organization. {%- elif level == 'community' and own -%}Community item — yours, and not verified by your organization. {%- elif level == 'community' -%}Community item — shared by other users and not verified by your organization. {%- endif -%} {%- endmacro -%} {%- macro _word(level) -%} {%- if level == 'org' -%}Organization {%- elif level == 'verified' -%}Verified {%- elif level == 'community' -%}Community {%- endif -%} {%- endmacro -%} {%- macro _glyph(level) -%} {%- if level == 'org' -%}building {%- elif level == 'verified' -%}shield-check {%- elif level == 'community' -%}users {%- endif -%} {%- endmacro -%} {%- macro mark(level, own=False, form='icon', extra_class='') -%} {%- set lvl = (level | trim) -%} {%- if lvl in ('org', 'verified', 'community') -%} {%- set tip = _tip(lvl, own) | trim -%} {%- set labelled = (form == 'label') -%} {{ _trust_ico.icon(_glyph(lvl) | trim, 13 if labelled else 14) }}{% if labelled %}{{ _word(lvl) | trim }}{% endif %} {%- endif -%} {%- endmacro -%}
