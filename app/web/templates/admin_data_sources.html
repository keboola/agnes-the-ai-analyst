Live queries, cost-guarded

Tables you add here are registered as live queries — no copy, every query runs in BigQuery behind the scan cap. For a saved query (materialized SQL on a schedule), partitioning or custom SQL, use Tables → Register new table — the full editor stays there.

{# CSV / files — honest guidance: there is no CSV connector. Files enter through Library Collections (per-file ingestion); a live system's export belongs in a data package instead. #}

Files become searchable through the Library, not a connector.

Upload documents (PDF, Markdown, CSV, …) into a Collection in the Library — Agnes ingests them per file and analysts search them with citations. A Collection is honest about being a snapshot: when the content changes, a person re-uploads.

If the file is an export of a live system, that system is the source — connect it (Keboola or BigQuery) and let a data package carry the tables, or the copy starts drifting the moment it lands. The trade-offs: Collections vs. data packages.
